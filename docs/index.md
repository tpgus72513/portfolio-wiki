# 나의 기술 포트폴리오

공부와 프로젝트에서 얻은 지식을 기록하고, 구현 결과뿐 아니라 문제를 정의하고 해결 범위를 결정한 과정까지 공유합니다.

## 대표 프로젝트

### [세종페이(PAYUS) — 캠퍼스 전용 QR 간편결제 플랫폼](projects/sejong-pay.md)

학생과 지역 가맹점을 연결하는 QR 결제 MVP에서 프론트엔드 화면, 디자인 시스템, 결제 흐름 통합과 삭제된 앱 소스 복구를 담당했습니다.

### [올클(AllCle) — 야구 티켓팅 연습 시뮬레이터](projects/ticketing-simulator.md)

고수요 티켓팅 과정을 1인 연습 경험으로 단순화하고, 상태 머신 기반 백엔드와 결정론적 매진 시뮬레이션을 구현한 팀 프로젝트입니다.

### [다이내믹 뷰티 큐레이터](projects/dynamic-beauty-curator.md)

정적 피부 정보와 위치별 환경 조건을 결합해 스킨케어 루틴을 추천하는 웹 기반 MVP입니다. 모델 통합의 한계와 외부 API 장애에 대응한 fallback 설계를 함께 정리했습니다.

### [AI 기반 소상공인 상권 분석·마케팅 지원 플랫폼](projects/ai-mentoring-internship.md)

상권 분석 결과를 마케팅 실행으로 연결하기 위해 자연어 콘텐츠 생성, 허위·과장 표현 검사, AI 장애 시 규칙 기반 대체 경로를 구현한 기업 멘토링 프로젝트입니다.

## 이 위키에서 다루는 내용

- 프로젝트에서 맡은 역할과 실제 기여
- 구현 중 마주친 문제와 해결 과정
- 의도적으로 제외한 기능과 그 이유
- 검증 방법, 한계, 다음 개선 방향
